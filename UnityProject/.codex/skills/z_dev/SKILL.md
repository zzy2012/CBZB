# Unity UI 预制体约定

- 窗口脚本与窗口根预制体同名；若项目使用资源定位配置，定位值也应匹配该预制体。
- 固定 UI 层级和组件保存在预制体中。运行时脚本只绑定节点、注册事件和更新状态，不用 `new GameObject` 或 `AddComponent` 拼装 UI。
- 可变列表项使用独立预制体实例化；代码只设置数据、布局和交互状态，并按项目约定管理实例及资源生命周期。
- 先遵循项目现有 UI 框架和资源 API；此约定不依赖特定框架。地图、单位等非 UI 世界对象不受此限制。
- 改造时保留原交互与视觉行为，保护已有资源修改；删除旧资源前先审计引用。
- 验证预制体名称、节点路径和组件绑定，运行构建及相关测试；条件允许时在 Unity Editor 验证导入和交互。不要为验证在同一工程启动第二个 Editor。
